# 部署指南（Deployment）

## 前置要求

| 依赖 | 版本 | 说明 |
|---|---|---|
| Docker / Docker Compose | 24+ / v2 | 推荐方式 |
| 或 JDK + Maven | 17+ / 3.8+ | 本地裸机部署 |
| 或 Node.js | 18+ | 前端构建 |

## 方式一：Docker Compose（推荐）

### 1. 构建前端静态资源

Compose 的 Nginx 容器直接挂载 `源码/vue3/dist`，先构建一次：

```bash
cd 系统/销售系统/源码/vue3
npm ci
npm run build   # 产物输出到 dist/
```

### 2. 配置环境变量（可选但建议）

```bash
cp .env.example .env
# 编辑 .env：更换 DB_PASSWORD、APP_JWT_SECRET（openssl rand -hex 32）
```

### 3. 一键启动

```bash
cd 系统/销售系统
docker compose up -d --build
```

启动内容：

| 容器 | 说明 |
|---|---|
| `greencert-mysql` | MySQL 8.4，首次启动自动导入 `数据库/db_aps_绿证版.sql` |
| `greencert-backend` | Spring Boot 后端，等 MySQL 健康检查通过后启动 |
| `greencert-frontend` | Nginx 1.27，托管前端静态资源并反代 `/api` |

### 4. 验证

- 前台/后台：<http://localhost:8080>
- 后端 API：<http://localhost:1234/api/product?page=1&size=1>
- Swagger：<http://localhost:1234/swagger-ui.html>

### 生产环境检查清单

- [ ] `APP_JWT_SECRET` 已更换为随机 64 位十六进制
- [ ] `DB_PASSWORD` 已更换为强密码
- [ ] RSA 密钥对已生成并注入 `APP_RSA_PRIVATE_KEY` / `APP_RSA_PUBLIC_KEY`（多实例必须）
- [ ] `SPRINGDOC_API_DOCS_ENABLED=false`、`SPRINGDOC_SWAGGER_UI_ENABLED=false`（关闭 API 文档）
- [ ] SMTP 授权码已配置或邮件功能已确认停用
- [ ] MySQL 端口未对公网暴露（删除 compose 中 mysql 的 ports 映射）
- [ ] 已为 Nginx 配置 HTTPS（建议 certbot / 云负载均衡）

## 方式二：本地裸机部署

### 1. 数据库

```sql
CREATE DATABASE db_aps DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

导入 `系统/销售系统/数据库/db_aps_绿证版.sql`。

### 2. 后端

```bash
cd 系统/销售系统/源码/springboot
export DB_HOST=localhost DB_PORT=3306 DB_NAME=db_aps
export DB_USER=root DB_PASSWORD=你的密码
export APP_JWT_SECRET=$(openssl rand -hex 32)
mvn spring-boot:run          # 或 mvn package 后 java -jar target/springboot-0.0.1-SNAPSHOT.jar
```

端口 `1234`。

### 3. 前端

开发模式：

```bash
cd 系统/销售系统/源码/vue3
npm run dev                  # http://localhost:8081，/api 已代理到 1234
```

生产模式：`npm run build` 后将 `dist/` 交给任意静态服务器（Nginx 示例见下）。

### Nginx 参考配置

`系统/销售系统/nginx.conf` 即容器内置配置，核心片段：

```nginx
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;

    # SPA history 路由回退
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://backend:1234;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 常见部署问题

<details>
<summary><b>后端连不上数据库？</b></summary>

检查 `DB_HOST`（compose 网络内应为服务名 `mysql`）、`DB_PASSWORD` 是否与 MySQL 容器一致；MySQL 健康检查通过前 backend 不会启动。
</details>

<details>
<summary><b>多实例部署后登录随机失败？</b></summary>

RSA 密钥未统一。每个实例注入相同的 `APP_RSA_PRIVATE_KEY` / `APP_RSA_PUBLIC_KEY`；JWT 密钥同理（`APP_JWT_SECRET`）。
</details>

<details>
<summary><b>前端刷新 404？</b></summary>

静态服务器缺少 SPA 回退配置，参考上方 `try_files` 片段。
</details>

<details>
<summary><b>邮件验证码发不出去？</b></summary>

配置 `MAIL_HOST` / `MAIL_USERNAME` / `MAIL_PASSWORD`；QQ 邮箱需开启 SMTP 并使用授权码（非登录密码）。
</details>
